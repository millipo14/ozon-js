# Vanilla JS Ozon Clone

Учебный проект интернет-магазина, реализующий базовую логику маркетплейса.  
Основной акцент сделан на клиентской архитектуре, модульной структуре JavaScript и работе с данными: каталог, фильтрация, поиск и корзина.

## Demo

Проект доступен по ссылке:  https://millipo14.github.io/ozon-js/

> Примечание: из-за отсутствия удалённого API часть данных (каталог товаров/изображения) может быть недоступна в демо-версии. Рекомендуется запуск локально.

## Технологии

- HTML5 / CSS3
- Vanilla JavaScript
- REST API (Fetch)
- LocalStorage (сохранение состояния корзины)

## Функциональность

### Каталог товаров
- Динамическая отрисовка карточек товаров
- Загрузка данных с API
- Разделение на категории

### Корзина
- Добавление и удаление товаров
- Подсчёт общей стоимости в реальном времени
- Сохранение состояния в LocalStorage

### Фильтрация и поиск
- Фильтр по цене
- Фильтр по скидкам
- Поиск по названию товаров
- Нормализация строк для корректного поиска

## Архитектура проекта

Проект разделён на независимые модули:

- `getData.js / postData.js` — работа с API
- `catalog.js / renderGoods.js` — загрузка и рендер каталога
- `cart.js / renderCart.js` — логика корзины
- `filter.js / filters.js` — чистые функции фильтрации
- `load.js` — инициализация приложения


## 📌 Примечание

Проект создан в учебных целях для практики работы с JavaScript, API и архитектурой фронтенд-приложений.
